# Legal Architecture

Design constraints applied from testnet:

- ERC-721 digital collectibles
- genuinely limited collectibles
- non-custodial marketplace
- no custody of user funds
- no custody of user NFTs
- non-transferable CHESS Credits
- no CHESS cash-out
- personal data kept off-chain
- Chess identity kept off-chain
- no gambling or player stakes
- Base Sepolia before Base Mainnet

The legal architecture will evolve progressively for mainnet and scale without redesigning the core protocol.
