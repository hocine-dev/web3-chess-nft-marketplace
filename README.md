# Web3 Chess NFT Marketplace

Full-stack Web3 chess collectibles marketplace built with Solidity, Ethereum/Base, ERC-721, Next.js and TypeScript.

## Core concepts

- on-chain ownership
- limited digital chess collectibles
- non-custodial NFT marketplace
- EVM / Ethereum-compatible architecture
- Base Sepolia testnet
- wallet integration
- chess-based rewards
- non-transferable CHESS Credits
- collector profiles
- secondary market

## Stack

### Blockchain

- Solidity
- Foundry
- OpenZeppelin
- Base / Ethereum EVM

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS
- Wagmi
- Viem

### Backend

- Node.js
- Fastify
- TypeScript
